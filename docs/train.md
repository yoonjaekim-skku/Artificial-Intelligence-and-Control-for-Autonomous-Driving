### 1.2.2. Observation: 49차원
확정된 observation이 아님

| 인덱스 | 항목 | 차원 | 내용 |
|---|---|---:|---|
| 0 | ego 속도 | 1 | 내 속도 / 기준 제한속도 |
| 1~20 | 주변 차량 | 20 | 좌2~우2 차선별 선행·후행 차량 거리와 상대속도, 앞뒤 50m 관측 |
| 21~29 | 기존 경로 연결성 | 9 | 좌4~우4 차선에서 경로의 바로 다음 도로로 연결되는지 확인 |
| 30~34 | 전방 차량 밀도 | 5 | 좌2~우2 차선별 관측 범위 내 차량 밀도 |
| 35~39 | 전방 신호 1개 | 5 | 안 보임/초록/노랑/빨강 one-hot 4차원 + 정지선 거리 1차원 |
| 40~48 | 추가 경로 연결성 | 9 | 좌4~우4 차선에서 경로의 다음 두 도로까지 중간 차선 변경 없이 연결되는지 확인 |

- 목적지 one-hot 및 두 번째 신호 관측은 제외.
- 주변 차량 거리: 50m 기준 정규화. 상대속도: `(상대 차량 속도 - ego 속도) / 기준 제한속도`.
- 신호 관측 범위: 정지선까지 100m. 거리 `clip(거리 / 100, 0, 1)`, 안 보이면 거리 1.
- 기존 연결성: 없는 차선 −1, 연결되면 1, 연결되지 않으면 남은 거리 / 50m. 남은 거리 50m 초과 또는 junction 내부에서는 1로 처리.
- 추가 연결성: 없는 차선 −1 / 연결 불가 0 / 연결 가능 1. 거리 제한 없이 조회하며 junction 내부에서도 실제 연결 확인. 보상·종료 판정에는 사용하지 않음.
- 최종 관측은 `[-1, 1]`로 제한.

### 1.2.3. Reward
확정된 reward가 아님

| 항목 | 보상·감점 | 적용 조건 |
|---|---|---|
| 속도 | `+0.1 × 속도 / 기준 제한속도` | 일반 주행 스텝 |
| 차선 변경 명령 | **−0.02** | 수락된 좌/우 변경 명령당 |
| 불가능한 차선 변경 명령 | **−0.2** | 거절된 좌/우 변경 명령당 |
| 앞차 접근 | −0.1 | 간격 6m 미만. 관측된 적신호 + 속도 0.5m/s 이하이면 면제 |
| 막힘 | −0.05 | 앞차 20m 이내 + 속도 기준 제한속도의 70% 미만. 적신호 관측 시 면제 |
| 적신호 거리 (삭제 예정) | `−0.05 × clip(min(앞차 여유, 정지선 여유) / 100, 0, 1)` | 적신호 관측 시, 속도 조건 없음. 앞차 여유 `max(간격−3m, 0)`, 정지선 여유 `max(거리−3m, 0)`. 앞차가 없으면 정지선 여유만 사용 |
| 청신호 통과 | +10 | 경로에 맞는 청신호 정지선 통과, 신호 ID당 에피소드 내 1회 |
| 적신호 위반 / 충돌 | 해당 스텝 보상을 −5로 대체 | 즉시 종료 |
| 도착 | 해당 스텝 보상을 +2로 대체 | 종료 |
| 잘못된 차선 | 일반 보상에 −2 추가 | 다음 경로로 연결되지 않는 차선 끝 5m 이내에서 속도 0.5m/s 미만, 종료 |
| 충돌·도착 외 ego 소실 | 해당 스텝 보상을 −2로 대체 | 종료 |
| 시간 초과 | 별도 감점 없음 | truncation, 학습 시 마지막 상태 가치로 bootstrap |

## 2. 모델 평가 방법
이 프로젝트의 최종 목적은
- 가능한 모든 출발지-목적지 조합 및 대안 도로에 대해서
- 다양한 신호 타이밍에 대해
- 충돌하지 않고 경로를 성공하는 것

위 목적을 달성하는지 모델을 평가하기 위해 다음과 같이 모델 평가 스크립트를 제작했다.
- 모델 평가 스크립트는 [scripts/evaluate.py](../scripts/evaluate.py)다. 모델 한 개의 저장 설정으로 Phase 1 또는 Phase 2를 평가한다. Phase 2는 각 도로의 신호 시작 시점을 저장 설정에 맞춰 무작위로 정한다.
- 평가 경로: 도로 목록이 서로 다른 23개 경로 (Ring 미경유 18개, Ring 경유 5개)
- 평가 횟수: 23개 경로 × seed 0~4 = 115회. 각 seed에서 23개 경로를 동시에 주행한다.

프로젝트 루트에서 실행한다. 해당 실험의 `analysis/learning_curve.png`에서 학습 곡선과 최종 경로별 완주·실패를 함께 확인할 수 있다.

```bash
conda activate sumo
python scripts/evaluate.py results/parallel_1_YYYYMMDD_HHMMSS_ffffff
```
