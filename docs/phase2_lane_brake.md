# Phase 2 병렬 학습 개선: 차선 선택과 늦은 브레이크

[Phase 2 병렬 학습](parallel_train.md) 설정 위에 세 가지를 더해서, seed와 관계없이 학습이 성공하도록 만든 기록이다.

## 한눈에 보기

| | 공유 설정 그대로 | 이 문서의 설정 |
|---|---|---|
| 성공한 seed (도착 94% 이상) | 3개 중 1개 | **5개 중 5개** |
| 도착 | 53.5%, 100%, 53.9% | 99.6% 이상 (5개 모두) |
| 잘못된 차선 | 실패 seed에서 약 46% | **0%** |
| 신호 위반 | 0%, 0%, 0.4% | 1,280번 중 1번 |
| 정지 거리 (중간값) | 6.0m (성공 seed) | 4.7m에서 8.3m |

모두 400만 step, 처음부터 학습, `scripts/evaluate_parallel.py`의 256개 경로 평가 기준이다. 실행 환경은 MacBook CPU, SUMO 1.27.1.

## 실행 방법

```bash
python train_parallel.py --phase 2 --num-envs 256 --steps-per-env 64 --iterations 244 \
    --minibatch-size 512 --eval-interval 0 \
    --set reward.off_route_lane_penalty=0.05 \
    --set reward.red_stop_penalty_coef=0.1 \
    --set reward.red_stop_distance_scale=50 \
    --set hparams.lane_keep_bias=0.0 \
    --set obs.lookahead_edges=3 \
    --set reward.late_brake_penalty_coef=0.1 \
    --set hparams.seed=0

python scripts/evaluate_parallel.py results/parallel_2_<시간>
```

앞의 세 `--set`은 기존 Phase 2 권장값이고, 뒤의 세 개가 이 문서에서 추가한 것이다. 새 옵션 두 개(`obs.lookahead_edges`, `reward.late_brake_penalty_coef`)는 기본값이 기존 동작과 같아서, 켜지 않으면 기존 학습에 영향이 없다.

## 문제 1: 교차로 전에 맞는 차선으로 못 옮김

**증상:** 공유 설정 그대로 seed 0, 1, 2를 학습하면 seed 1만 성공했다. seed 0과 2는 도착 약 54%, 잘못된 차선 약 46%였다. 실패는 중앙 교차로를 지나는 직접 경로에 몰렸다 (A1→A4 10/10, A4→A2 16/18 등). 원형도로 경로는 항상 성공했다.

**원인:** 노형오거리 진입로는 거의 모두 아래 구조다.

```
[긴 진입로 약 220m] → [짧은 구간 23-44m] → [짧은 구간 24-29m] → 교차로
```

추가 연결성 관측(`_lookahead_connectivity_observation`)은 앞의 route edge **2개**까지만 확인한다. 긴 진입로에서 2개 앞은 아직 교차로 전이라, 교차로에서 어느 차선이 목적지로 이어지는지가 보이지 않는다. 목적지 one-hot도 꺼져 있어서 정책은 긴 진입로에서 회전 차선을 알 방법이 없다.

경로 파일과 net 파일로 첫 edge의 각 차선을 확인한 결과 (차선 0 = 맨 오른쪽):

| 경로 | 2개만 볼 때 "가능" | 실제로 가능한 차선 |
|---|---|---|
| A1→A1 (유턴) | 1, 2, 3, 4 | 4만 |
| A1→A2 | 1, 2, 3, 4 | 1, 2, 3 |
| A1→A4 | 1, 2, 3, 4 | 4만 |
| A1→A5 | 1, 2, 3, 4 | 1, 2, 3 |
| A4→A2 | 1, 2 | 2만 |
| A4→A3 | 1, 2 | 1만 |

정책은 짧은 구간에 들어가서야 틀린 차선임을 알게 되고, 그때는 차선 변경과 감속을 50m 안에서 같이 해야 해서 실패한다. Phase 1(항상 초록불)에서는 멈추지 않고 달리면서 바꿀 수 있어서 이 문제가 드러나지 않은 것으로 보인다.

**해결 1: `obs.lookahead_edges=3`** (`env/sumo_env.py`)

내다보는 route edge 수를 설정으로 바꿀 수 있게 했다 (기본 2). 3이면 22개 경로의 모든 edge, 모든 차선에서 "route 끝까지 전부 확인한 결과"와 일치한다 (불일치 0개). 관측 크기(49차원)는 그대로다. 도로 구조가 바뀌면 3으로 충분한지 다시 확인해야 한다.

**해결 2: `hparams.lane_keep_bias=0.0`**

차선 head의 "유지" 초기 편향(0.5)을 없앤다. 학습 초반에 차선 변경을 더 많이 시도해서, 바꿔야 할 때를 배울 기회가 늘어난다. 단독으로는 seed 5개 중 4개 성공이었다 (아래 실험표).

## 문제 2: 빨간불에 정지선을 1m쯤 넘음

**증상:** 해결 1, 2를 적용하면 차선 실패는 사라지지만 신호 위반이 0.4%에서 1.6% 남았다. seed 3에서는 위반 4번이 모두 A2→A1 경로였다.

**원인:** 한 대를 추적하면, 145m 앞부터 빨간불이 보이는데도 정지선 62m 앞까지 13.9m/s를 유지하고, 그 뒤 1-2m/s²로만 감속해서 1.2m/s로 정지선을 넘었다. 신호를 무시한 것이 아니라 브레이크가 늦고 약했다 (ego 최대 감속은 5.4m/s²). 정지 위치 감점은 "최대한 늦게, 가깝게" 서는 것을 유리하게 만들어서 가끔 이런 위반이 생긴다.

**해결 3: `reward.late_brake_penalty_coef=0.1`** (`env/sumo_env.py`)

빨간불일 때 정지선까지 서는 데 필요한 감속 `v² / 2d`가 기준(`late_brake_decel`, 기본 2.5m/s²)을 넘으면 매 step 감점한다. 크기는 `coef × clip((필요 감속 − 기준) / 기준, 0, 1)`. 기본값 0(꺼짐).

## 실험 기록

모두 공유 설정(경로 밖 차선 감점 0.05, 정지 감점 0.1, 정지 거리 스케일 50) 위에서 400만 step. 칸의 값은 도착률.

| 설정 | seed 0 | seed 1 | seed 2 | seed 3 | seed 4 |
|---|---|---|---|---|---|
| 공유 설정 그대로 | 53.5% | 100% | 53.9% | | |
| + lane_keep_bias=0 | 100% | 99.6% | 94.1% | 53.9% | 99.6% |
| + lookahead_edges=3 | 99.2% | 100% | 100% | 98.4% | 99.2% |
| + late_brake_penalty (최종) | **100%** | **99.6%** | **100%** | **100%** | **100%** |

최종 설정의 세부 결과:

| seed | 도착 | 신호 위반 | 잘못된 차선 | 정지 거리 (중간값) |
|---|---|---|---|---|
| 0 | 100% | 0% | 0% | 5.5m |
| 1 | 99.6% | 0.4% | 0% | 4.7m |
| 2 | 100% | 0% | 0% | 5.1m |
| 3 | 100% | 0% | 0% | 8.3m |
| 4 | 100% | 0% | 0% | 5.6m |

### 시도했지만 채택하지 않은 것

| 설정 | seed 0 | seed 2 | 판단 |
|---|---|---|---|
| lane_entropy_coef 0.01→0.03 | 55.1% | 99.6% | 한 seed만 성공, 효과 불분명 |
| off_route_lane_penalty 0.05→0.1 | 100% | 53.5% | 한 seed만 성공, 효과 불분명 |
| lookahead_edges=3 + 이른 경로 밖 차선 감점 0.02 | 93.8% (seed 0) | 100% (seed 3) | seed 0에서 잘못된 차선 6.3% 발생, 관측 수정만으로 충분 |

이른 경로 밖 차선 감점은 "앞으로 3개 edge까지 이어지지 않는 차선이면 거리와 무관하게 매 step 감점"이다. 채택하지 않아서 코드에는 넣지 않았다.

## 한계

- 실패를 미리 알 수 있는 신호: 학습 중 `ep_rew_mean`이 끝까지 5-7에 머무르면 실패했고, 성공한 학습은 12-16이었다.
- `lane_keep_bias=0`을 빼고 `lookahead_edges=3`만으로 충분한지는 확인하지 않았다.
- 같은 seed라도 컴퓨터와 SUMO 버전에 따라 결과가 다를 수 있다. 공유 설정이 다른 환경에서 seed 3개 모두 성공한 것과 이 문서의 결과가 다른 이유로 추정한다.
- 배경 차량이 없는 Phase 2 결과다.
